Some of my Projects

Analytics Dashboard for CDR

This Analytics Dashboard is a Streamlit application that provides an interactive interface for analysing call activity, operational performance and regional trends. Unlike traditional dashboards that process data locally, all business logic and analytics are retrieved from a secured FastAPI backend through authenticated REST API requests. Users authenticate using JWT credentials before accessing protected dashboard resources.

The dashboard was designed to provide a user-friendly interface for visualizing and exploring call data, while also demonstrating secure API integration and real-time data retrieval.

Technologies used:
  • Python
  • Pandas
  • Streamlit
  • RESTful API
  • FAST API
  • JWT
  • MongoDB
  • Pydantic

Ebook Store Database Manager

A command-line Python and SQLite application that manages an ebook store's inventory, demonstrating core relational database fundamentals. It uses a normalized schema linking books and authors through a foreign key relationship, and supports full CRUD operations along with search by ID, title, and author.

Built to reinforce schema design, SQL querying, and data integrity — translating a real inventory-tracking requirement into a working relational data model.

Technologies used:
  • Python
  • SQLite
  • SQL

Sentiment Analysis: Amazon Product Reviews

This project performs sentiment analysis on Amazon product reviews using Python natural language processing libraries. The main script allows a user to load a review dataset, preprocess the review text, remove stop words, analyse the sentiment of individual reviews, and compare the similarity between two reviews.

The project is implemented as a menu-driven command-line application and is designed to demonstrate practical NLP preprocessing and review analysis workflows.

Technologies used:
  • Python
  • Pandas
  • SpaCy
  • TextBlob
